# ry21-problem-solving

Solutions to problems from LeetCode, HackerRank, and Codeforces, organized by platform. Each problem folder holds a `README.md` with the original link, difficulty, tags, and notes, plus one subfolder per language used to solve it.

Run `npm run reindex` after adding a problem to regenerate the table below.
