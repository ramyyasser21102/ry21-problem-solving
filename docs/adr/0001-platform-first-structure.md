# Platform-first repository structure

Problems are organized primarily by platform (`leetcode/`, `hackerrank/`, `codeforces/`), not by topic or pattern (e.g. `arrays/`, `dp/`) as many algorithm-practice repos do. Platforms differ enough in numbering, difficulty scales, and problem identifiers that forcing a shared topic-first taxonomy across all three would add friction without much benefit. Topic is still captured, just as `tags` metadata on each problem rather than as the folder structure itself.
